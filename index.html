How to Play

🎯 Find the odd color on the board.

🎨 Choose the exact matching color.

🧠 Watch the color sequence, then repeat it in order.

Each round has its own time limit. Faster correct answers earn more points. Online matches use 10 rounds per set; first to 3 set wins takes the series.

Connection Settings

Enter your Supabase Project URL and anon / publishable key only.
