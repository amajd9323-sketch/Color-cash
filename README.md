# Color Clash

لعبة تحدّي ألوان سريعة، مهيأة للهاتف، مع لعب فردي ومنافسة مباشرة 1 ضد 1 عبر الإنترنت.

## محتوى اللعبة
- اكتشاف اللون المختلف، مطابقة اللون، وتحدي الذاكرة.
- جولات خاصة: العثور على لونين مختلفين، الذاكرة العكسية، الألوان المتقاربة، الذاكرة السريعة، وجولة السرعة.
- كل مجموعة 10 جولات. أول لاعب يفوز بثلاث مجموعات يحسم السلسلة (Best of 5).
- ملفات شخصية، صور رمزية، ثيمات، مؤثرات صوت واهتزاز اختيارية.
- تفاعلات أثناء المباراة، سجل نتائج، إحصائيات، وإنجازات.
- واجهة إنجليزية وتركية وغرف خاصة برمز انضمام.

## نظام القدرات العادل
- لكل لاعب قدرتان فقط في المجموعة الواحدة.
- قدرة واحدة فقط في الجولة.
- كل نوع قدرة يمكن استخدامه مرة واحدة في المجموعة.
- استخدام أي قدرة يخفض نقاط تلك الجولة 25%.
- التلميح مساعدة جزئية ولا يكشف الإجابة.
- التجميد 1.8 ثانية، وزيادة الوقت 5 ثوانٍ فقط.
- الخادم يطبق الحدود والخصم؛ إعادة تحميل الصفحة لا تعيد القدرات.

اللعب بدون قدرات يبقي أعلى نتيجة ممكنة. الفوز يعتمد على سرعة الإجابة ودقتها، لا على كثرة القدرات.

## إعداد Supabase
1. فعّل Anonymous Sign-Ins من Authentication.
2. شغّل ملف `supabase.sql` مرة واحدة في SQL Editor لإنشاء الجداول والدوال الأساسية.
3. شغّل `supabase-color-clash-fair-play.sql` لإضافة قواعد القدرات العادلة وسجل المواجهات.
4. افتح اللعبة على الجهازين؛ أنشئ غرفة وشارك الرمز مع اللاعب الثاني.

لا تضع مفتاح `service_role` في المتصفح. التطبيق يستخدم مفتاحاً عاماً، وتُقيد قراءة الغرف والسجل بسياسات RLS.

**تنبيه:** لا تعِد تشغيل `supabase.sql` على قاعدة بيانات مستخدمة؛ يحتوي على أوامر حذف وإعادة إنشاء لجداول تجريبية سابقة. ملف `supabase-color-clash-fair-play.sql` إضافة آمنة لا تحذف الغرف أو الملفات الشخصية أو النتائج.

## GitHub Pages وAPK
- نشر الويب يتم عبر `.github/workflows/pages.yml` عند الدفع إلى `main`.
- بناء APK من تبويب Actions عبر **Build Android APK**.
- بعد نجاح البناء، نزّل Artifact باسم `Color-Clash-debug-APK` ثم فك ضغطه للحصول على `app-debug.apk`.
- الناتج الحالي APK تجريبي Debug؛ إصدار المتجر يحتاج إعداد توقيع خاص.

## الملفات الرئيسية
- `index.html`: واجهة اللعبة وآليات التحدي والاتصال والسجل.
- `supabase.sql`: إعداد قاعدة البيانات الأساسية.
- `supabase-color-clash-fair-play.sql`: حدود القدرات وخصم النقاط وسجل المواجهات.
- `manifest.json` و`icon.svg`: بيانات التطبيق وأيقونته.
- `sw.js`: التخزين المؤقت ونسخة الكاش.
- `.github/workflows/android-apk.yml`: فحص JavaScript وبناء APK.
